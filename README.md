📖 Descripción

Repositorio oficial del Proyecto Integrador de Tecnologías de Información, enfocado en el diseño e implementación de un Data Center Académico virtualizado.

Este repositorio contiene:

📄 Documentación técnica del proyecto

🗺️ Diagramas físicos y lógicos

⚙️ Scripts de configuración y automatización

🖥️ Configuraciones de servicios (AD, DHCP, DNS, Correo, VoIP)

🐳 Archivos Docker y docker-compose

💾 Configuración de almacenamiento (NAS – OpenMediaVault)

🔐 Evidencias de seguridad, firewall y respaldos

La infraestructura está basada en Proxmox VE, integrando servicios empresariales como Active Directory, servidor de correo (hMailServer), central IP, contenedores Docker y almacenamiento en red.
